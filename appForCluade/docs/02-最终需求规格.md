# 02-最终需求规格.md

> 融合 PRD V2.2 > V2.1 > V1.0 + HTML 原型的最终需求规格

---

## 1. 产品定位

**名称**: 奇妙脑力岛 (BrainIsland)
**目标**: 3-6岁儿童，通过游戏化训练专注力、记忆力、逻辑思维、阅读理解
**运行模式**: 完全本地离线 (zero network required for core features)
**AI辅助生产**: 图片/声音/语音由 AI 自动生成 (后续阶段)

## 3. 用户角色

### 3.1 儿童用户 (3-6岁)
- **界面**: 大按钮 (≥56dp), 大图片, 大图标, 少文字, 圆角, 明亮, 动画, 语音
- **操作**: 单一点击/拖拽, 无复杂菜单
- **反馈**: 即时动画 + 语音, 无负面评价
- **导航**: 4个底部 Tab 最大 (首页 / 学习 / 故事 / 我的)

### 3.2 家长用户
- **入口**: 儿童端长按家长图标 → 4位数字 PIN
- **功能**: 查看能力成长, 学习记录, 设置时间限制, 修改 PIN
- **PIN**: 默认 `1234` (HTML 原型), 可自定义

- 显示 4个能力卡片

### 4.4 故事中心 (Story / Reading)
- **级别自动分级**: 根据年龄 → A/B/C/D

- **100篇文章**: Level A~D, 每级25篇
- **阅读引擎入口**: 5个阅读游戏

### 4.5 我的 (Profile)
- 当前孩子头像/昵称
- 星星数量
- 成就徽章
- 角色/家园装饰 (原型为 Toast 提示, V2.2 标记为后续)

## 5. 游戏系统

### 5.1 20个核心游戏

| # | 能力 | 游戏ID | 游戏名称 | 核心机制 |
|---|------|-------|---------|---------|
| 1 | 专注 | find_target | 找一找 | 从 N 个物体中找指定动物 |
| 2 | 专注 | find_diff | 找不同 | 找出 N 个元素中唯一不同 |
| 3 | 专注 | visual_track | 视觉追踪 | 记住星星在哪个杯子 |
| 4 | 专注 | eliminate_interf | 消除干扰 | 只点指定类别 (水果/动物/...) |
| 5 | 专注 | auditory_att | 听觉注意 | 听声音找对应动物 |
| 6 | 记忆 | card_flip | 翻牌记忆 | 翻牌配对 |
| 7 | 记忆 | seq_memory | 顺序记忆 | 记忆序列位置 |
| 8 | 记忆 | pic_memory | 图片记忆 | 记住出现过的图案 |
| 9 | 记忆 | pos_memory | 位置记忆 | 记住物品放置位置 |
| 10 | 记忆 | story_memory | 故事记忆 | 听故事答题 |
| 11 | 逻辑 | categorize | 分类 | 拖拽到正确篮子 |
| 12 | 逻辑 | order_by | 排序 | 按大小/体积顺序 |
| 13 | 逻辑 | pattern | 找规律 | 完成颜色/图形序列 |
| 14 | 逻辑 | shape_reason | 图形推理 | 完成图形序列 |
| 15 | 逻辑 | conditional | 条件推理 | 推理最高/最快 |
| 16 | 阅读 | story_quiz | 读文答题 | 读文章答选择题 |
| 17 | 阅读 | story_listen | 听故事 | TTS 朗读后答题 |
| 18 | 阅读 | story_sequence | 故事排序 | 拼正确句子顺序 |
| 19 | 阅读 | story_character | 人物判断 | 找出谁做了什么 |
| 20 | 阅读 | story_cause | 因果推理 | 分析为什么会这样 |

### 5.2 统一游戏生命周期
```
IDLE → INTRO → DEMO → PLAYING → SUCCESS/FAILURE → REWARD → FINISH
```
- **IDLE**: 加载资源, 初始化状态
- **INTRO**: 显示游戏标题 + TTS 指令
- **DEMO**: 展示游戏玩法 (点击任意取消)
- **PLAYING**: 玩家操作, 3轮/3题
- **SUCCESS/FAILURE**: 即时反馈 (动画 + 语音)
- **REWARD**: 星星动画 + 恭喜页面
- **FINISH**: 返回首页/学习页

### 5.3 游戏难度
- **等级**: 1~10
- **动态调整**:
  - 连续 3 次正确率 ≥ 90% → difficulty +1
  - 连续 2 次正确率 ≤ 50% → difficulty -1
  - 50% < accuracy < 90% → 保持
- **调整内容**: 物体数量, 干扰物, 时间限制, 选项相似度

### 5.4 提示系统
- 每个游戏支持 `hintCount`
- **禁止直接给答案**
- 提示范例: "再仔细看看，它的耳朵是什么形状？"

### 5.5 游戏时间
- 默认: 单局 30秒 ~ 5分钟
- 复杂故事: 最多 10分钟

## 6. 阅读理解题库

### 6.1 数据结构
```json
{
  "id": "A01",
  "level": "A",
  "theme": "animal",
  "title": "小猫钓鱼",
  "text": "小猫去河边钓鱼。\n河水清清的...",
  "questions": [
    {
      "q": "小猫去哪里钓鱼？",
      "a": "河边",
      "opts": ["河边", "山顶", "花园"]
    }
  ]
}
```

### 6.2 题目统计
| 级别 | 年龄 | 篇数 | 题型 | 文章长度 |
|------|------|------|------|---------|
| A | 3岁 | 25 | 2题/篇 | 50-80字 |
| B | 4岁 | 25 | 3题/篇 | 80-120字 |
| C | 5岁 | 25 | 3题/篇 | 120-180字 |
| D | 6岁 | 25 | 3-4题/篇 | 180-250字 |

**总计**: 100篇 × 平均 3题 = ~300题

### 6.3 阅读引擎交互
1. **故事展示阶段**: 显示完整文章 (标题 + 正文)
2. **答题阶段**: 点击"开始答题" → 进入选择题
3. **story_listen**: 进入时自动 TTS 朗读全文, 暂停按钮在展示阶段隐藏

```text

  accuracy * 0.5
  + speedScore * 0.15
  + independenceScore * 0.15

newScore = oldScore * 0.7 + performance * 0.3
```

## 10. 音频系统

### 10.1 音频类型
- 背景音乐 (BGM): 3种 (主页/游戏/阅读), 循环, 15% 音量
- 音效 (SFX): 8种 (点击/成功/失败/翻页/弹窗/奖励/开始/完成)
- 动物声音: 9种 (猫/狗/鸟/牛/羊/鸭/狮/虎/象)
- TTS: Web Speech API equivalent (Android TextToSpeech)

### 10.2 TTS 参数
```text
语言: zh-CN
语速: 0.85
音调: 1.2
```

### 10.3 音频降级
- 音频资源不存在 → App 仍然运行, 不崩溃

## 13. 非功能性需求

### 13.1 性能
- **启动时间**: ≤ 3秒
- **游戏响应**: ≤ 200ms
- **动画帧率**: ≥ 50fps
- **APK 大小**: < 50MB (无网络图片/音频外联)

### 13.2 安全
- 无网络权限
- PIN 加密存储
- 无个人信息收集
- 合规资源 (AI 生成 / CC0 / 商业授权)

### 13.3 测试
- **单元测试**: ≥ 80%
- **集成测试**: 游戏生命周期, 数据库操作
- **E2E测试**: 首页 → 学习 → 游戏 → 结果 → 首页
