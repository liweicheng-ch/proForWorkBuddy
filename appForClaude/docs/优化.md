2. 本次优化的核心目标

不要把本项目简单开发成"儿童小游戏合集"。

最终产品应该形成：

儿童思维训练 + 专注力训练 + 记忆训练 + 阅读理解 + 故事冒险 +
游戏化成长 + 本地能力画像

整体产品概念：

孩子是在"奇妙脑力岛"中冒险、闯关、帮助角色解决问题，而不是单纯刷题。

因此，所有新增游戏和阅读理解内容，都应该优先考虑：

趣味性

儿童友好

游戏化

能力训练价值

关卡成长

可扩展性

数据驱动

离线运行

与现有 HTML 原型风格统一

7. 第一批重点新增/优化游戏

第一阶段优先实现以下 12 个精品玩法。

7.1 注意力雷达

玩法：

屏幕出现大量目标和干扰物。

例如：

动物、植物、交通工具、数字、图形等混合出现。

系统要求：

找出所有会动的小兔子。

逐级增加：

干扰项

目标相似度

时间压力

训练：

持续注意

7.2 禁止点击

玩法：

不同颜色、形状、动物或图案快速出现。

例如：

绿色 → 点击

红色 → 禁止点击

后续升级：

动物点击、水果不点击

大图点击、小图不点击

出现 A 点击、出现 B 禁止点击

规则中途切换

训练：

抑制控制

执行功能

规则切换

7.3 记忆闪卡

短时间展示一组图片：

动物、数字、交通工具、水果、图形等。

哪个图片没有出现？

哪个图片出现过？

第几个位置是什么？

逐级增加：

训练：

工作记忆

顺序记忆

7.4 记忆路线

11. 阅读理解模块------核心优化方向

阅读理解不能设计成：

一篇文章 + 5道选择题。

应该升级成：

故事 + 听读 + 图片 + 游戏 + 推理 + 排序 + 人物理解 + 情节预测 +
表达

阅读模块建议命名：

故事探险

12. 阅读理解六层体系

Level 1：听故事

系统自动朗读故事。

孩子听：

然后回答：

谁去了森林？

去了哪里？

看到了什么？

支持：

播放

暂停

上一句

下一句

再听一次

训练：

14. Level 3：故事排序

25. 错题不要机械重复

如果孩子某种题连续错误：

不要完全重复原题。

应该：

原题 ↓ 同知识点简单题 ↓ 相似题 ↓ 换场景 ↓ 提高难度

形成：

错题 → 巩固 → 迁移 → 提升

难度 +1

连续错误 2 次：

难度 -1

但不要突然大幅调整。

应该渐进变化。
