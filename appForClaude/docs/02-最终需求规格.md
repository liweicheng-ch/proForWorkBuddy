> 融合 PRD V2.2 > V2.1 > V1.0 + HTML 原型的最终需求规格

---

## 1. 产品定位

**名称**: 奇妙脑力岛 (BrainIsland)
**目标**: 3-6岁儿童，通过游戏化训练专注力、记忆力、逻辑思维、阅读理解
**运行模式**: 完全本地离线 (zero network required for core features)
**AI辅助生产**: 图片/声音/语音由 AI 自动生成 (后续阶段)

## 3. 用户角色

### 3.1 儿童用户 (3-6岁)
- **界面**: 大按钮 (≥56dp), 大图片, 大图标, 少文字, 圆角, 明亮, 动画, 语音
- **操作**: 单一点击/拖拽, 无复杂菜单
- **反馈**: 即时动画 + 语音, 无负面评价
- **导航**: 4个底部 Tab 最大 (首页 / 学习 / 故事 / 我的)

### 3.2 家长用户
- **入口**: 儿童端长按家长图标 → 4位数字 PIN
- **功能**: 查看能力成长, 学习记录, 设置时间限制, 修改 PIN
- **PIN**: 默认 `1234` (HTML 原型), 可自定义

## 5. 游戏系统

### 5.1 核心游戏体系 (8大能力 × 精品玩法)

基于优化方案，建立 **12个精品核心玩法**，覆盖 8大能力，每个玩法具备完整的游戏逻辑、关卡体系、难度递进、数据驱动配置。

| # | 能力 | 游戏ID | 游戏名称 | 核心机制 | 训练目标 |
|---|------|-------|---------|---------|---------|
| 1 | 专注力 | attention_radar | 注意力雷达 | 屏幕大量目标/干扰物混合移动，找出所有会动的小兔子 | 选择性注意、持续注意、抗干扰 |
| 2 | 专注力 | attention_inhibition | 禁止点击 | 不同颜色/形状/动物快速出现，绿色点击红色禁止，规则中途切换 | 抑制控制、执行功能、规则切换 |
| 3 | 记忆力 | memory_flashcard | 记忆闪卡 | 短时展示一组图片(动物/数字/交通/水果/图形)，隐藏后问答 | 工作记忆、视觉记忆、顺序记忆 |
| 4 | 记忆力 | memory_path | 记忆路线 | 展示路线 A→B→C→D 后隐藏，孩子重新选择正确路线 | 空间工作记忆、顺序记忆、路径规划 |
| 5 | 观察力 | detective_scene | 小小侦探 | 卡通场景(房间/公园/森林/海边/学校/城堡)中寻找线索 | 观察力、注意力、信息提取、推理 |
| 6 | 逻辑力 | logic_sorting | 神奇排序 | 拖拽对象按大小/重量/数量/年龄/速度/时间/长短/先后顺序排序 | 比较、分类、序列、逻辑思维 |
| 7 | 逻辑力 | logic_pattern | 找规律 | 图形/颜色/数字/数量/方向/组合/多条件规律，选择下一个 | 模式识别、逻辑推理、抽象思维 |
| 8 | 空间能力 | spatial_rotation | 空间旋转 | 展示图形，要求顺时针旋转 90°/180°/270°/镜像/多图形/立体后是什么 | 空间想象、视觉旋转、空间关系 |
| 9 | 空间能力 | maze_adventure | 迷宫探险 | 迷宫+小动物/宝箱/障碍/钥匙/门/星星/限时/最短路径/多出口 | 空间能力、路径规划、计划能力、问题解决 |
| 10 | 阅读理解 | reading_sequence | 故事排序 | 给出 3~8 个故事事件拖拽排序(发现胡萝卜→进入森林→遇到小熊→回家) | 时间顺序、事件理解、情节理解、因果关系 |
| 11 | 阅读理解 | reading_inference | 故事推理 | 故事提供信息，问题需根据上下文推理(天空变暗→带伞，为什么？) | 信息提取、因果推理、上下文理解 |
| 12 | 阅读理解 | reading_theory_of_mind | 人物心理推理 | 通过行为/语言/表情/环境推测心理(低头不语→难过)，高级需选证据 | 人物理解、情绪推理、文本证据、推理能力 |

**设计原则**：
- 每个游戏具备：游戏目标、规则、开始、过程、用户操作、正确/错误反馈、得分、时间/步数、关卡、难度、结束、星级评价、下一关、重新开始、数据保存
- 禁止：点击按钮直接完成、假游戏、静态页面、单题、TODO冒充功能、随机文本冒充游戏、所有游戏用同一模板
- 所有游戏关卡配置数据驱动化 (assets/data/levels.json)

### 5.2 冒险任务系统

**核心理念**：孩子在"奇妙脑力岛"中冒险、闯关、帮助角色解决问题，不是单纯刷题。

**任务结构示例**：
```
任务：帮小熊找回失踪的星星
→ 观察游戏(小小侦探) ↓ 记忆游戏(记忆闪卡) ↓ 迷宫探险 ↓ 逻辑推理(找规律) ↓ 阅读故事(故事推理) ↓ 最终宝箱
```

**任务奖励**：星星、金币、宝石、勋章、角色、岛屿装饰

**任务配置**：data-driven (assets/data/adventures.json)，每个任务包含：任务ID、标题、描述、关卡序列(游戏ID+难度)、奖励配置、解锁条件

### 5.3 奇妙脑力岛世界观

| 区域 | 对应能力 | 解锁条件 | 视觉风格 |
|------|---------|---------|---------|
| 中央岛 | 入口/总览 | 默认开放 | 欢迎中心、今日任务、奖励入口 |
| 专注岛 | 专注力 | 完成专注入门任务 | 雷达扫描、信号塔、灯塔 |
| 记忆森林 | 记忆力 | 完成记忆入门任务 | 树屋、记忆果实、回声洞 |
| 逻辑城 | 逻辑力 | 完成逻辑入门任务 | 齿轮塔、规律桥、推理法庭 |
| 谜题山谷 | 观察力 | 完成观察入门任务 | 侦探事务所、线索洞穴、谜题石 |
| 故事王国 | 阅读理解 | 完成阅读入门任务 | 图书馆城堡、故事树、预言池 |
| 空间迷宫 | 空间能力 | 完成空间入门任务 | 旋转塔、迷宫宫殿、镜像湖 |
| 数字乐园 | 数学思维 | 完成数学入门任务 | 数字花园、计算游乐场 |
| 太空基地 | 反应力 | 完成反应入门任务 | 发射台、轨道站、信号塔 |

**原则**：世界观服务于训练，不为装饰增加复杂系统。儿童通过训练逐渐解锁区域。

### 5.4 统一游戏生命周期 (保持不变)
```
IDLE → INTRO → DEMO → PLAYING → SUCCESS/FAILURE → REWARD → FINISH
```
- **IDLE**: 加载资源, 初始化状态
- **INTRO**: 显示游戏标题 + TTS 指令
- **DEMO**: 展示游戏玩法 (点击任意取消)
- **PLAYING**: 玩家操作, 3轮/3题
- **SUCCESS/FAILURE**: 即时反馈 (动画 + 语音)
- **REWARD**: 星星动画 + 恭喜页面
- **FINISH**: 返回首页/学习页

### 5.5 游戏难度自适应系统

- **等级**: 1~10
- **动态调整规则**：
  - 连续 3 次正确率 ≥ 90% → difficulty +1
  - 连续 2 次正确率 ≤ 50% → difficulty -1
  - 50% < accuracy < 90% → 保持
- **调整内容**：物体数量、干扰物、时间限制、选项相似度、移动速度、路径长度、分叉数量
- **渐进变化**：不要突然大幅调整，平滑过渡
- **记录维度**：正确率、错误次数、完成时间、连续正确、连续错误、当前难度

### 5.6 提示系统 (保持不变)
- 每个游戏支持 `hintCount`
- **禁止直接给答案**
- 提示范例: "再仔细看看，它的耳朵是什么形状？"

### 5.7 游戏时间 (保持不变)
- 默认: 单局 30秒 ~ 5分钟
- 复杂故事/任务: 最多 10分钟

### 5.8 计分规则 (参考原型)
- 单次作答：答对 +3星，答错 500ms 后可重试
- 找全类：找全 4个 +4星
- 配对类：翻牌 +pairs*2；排序 +数量*2
- 追踪：正确 +3
- 结算 total = 累计星 + (打满 3轮 +5) + 10
- 星级：>=12=3星 / >=6=2星 / 否则 1星

## 6. 故事探险 (原阅读理解模块)

### 6.1 核心理念
阅读理解不再是简单的“文章 + 选择题”，而是一场结合了听、读、看、玩、推的综合探险。

### 6.2 阅读理解六层体系 (Level 1~6)

| 级别 | 名称 | 核心玩法 | 训练目标 |
|---|---|---|---|
| **L1** | **听故事** | 系统自动朗读故事，孩子通过听力回答基础问题 (谁/哪里/什么) | 听觉注意、信息提取 |
| **L2** | **看图理解** | 展示完整卡通场景，孩子点击场景中正确角色/物品回答问题 | 场景理解、信息定位、观察力 |
| **L3** | **故事排序** | 将故事拆分为多个事件片段，孩子通过拖拽恢复正确顺序 | 时间顺序、情节理解、事件关系 |
| **L4** | **寻找线索** | 文章包含隐含信息，需根据上下文推理出答案 (如：天暗→带伞) | 因果关系、上下文理解、信息整合 |
| **L5** | **人物心理推理** | 通过行为/语言/表情推测心情，高级关卡需选择支持判断的证据 | 人物理解、情绪推理、文本证据 |
| **L6** | **隐藏信息推理** | 答案不直接出现在文中，需通过常识+文本逻辑推断 (如：放学回家+晚饭→时间) | 逻辑演绎、综合推理、常识应用 |

### 6.3 题型多样化
禁止单一 ABCD 选项，必须支持以下题型：
- **选择类**: 单选、多选、判断
- **交互类**: 拖拽排序、连线匹配、场景点击、图片选择
- **推理类**: 找证据、原因推理、结果预测、人物心情分析
- **听力类**: 听故事回答、情节排序

### 6.4 特色功能
- **故事预测**: 在关键节点暂停故事 $\rightarrow$ 预测接下来的情节 $\rightarrow$ 继续播放验证。
- **独立听力模式**: 无文本展示，纯音频输入 $\rightarrow$ 考察听觉记忆与理解。
- **阅读高亮朗读**: TTS 朗读时，当前句子自动高亮，支持播放/暂停/上下句/重播。
- **轻量故事创作**: 提供人物/动物/地点/道具/天气等元素，孩子通过拖拽组合创建自己的故事 (本地保存)。

## 7. 能力画像与评分系统

### 7.1 多维能力画像
不再使用单一分数，建立多维能力矩阵，用于精准分析孩子的认知状态。

| 能力维度 | 评估指标 | 训练重点 |
|---|---|---|
| **专注力** | 视觉搜索、抗干扰、持续注意、抑制控制 | 专注力 $\rightarrow$ 抑制控制 $\rightarrow$ 持续注意 |
| **记忆力** | 短时记忆、工作记忆、顺序记忆、位置记忆 | 记忆力 $\rightarrow$ 顺序记忆 $\rightarrow$ 工作记忆 |
| **观察力** | 细节识别、变化发现、视觉辨别 | 观察力 $\rightarrow$ 细节辨别 $\rightarrow$ 变化发现 |
| **逻辑力** | 推理、规律、分类、排序、因果 | 逻辑力 $\rightarrow$ 分类 $\rightarrow$ 规律 $\rightarrow$ 推理 |
| **阅读理解** | 信息提取、因果推理、人物理解、情节预测、听读 | 听读 $\rightarrow$ 提取 $\rightarrow$ 推理 $\rightarrow$ 理解 |
| **数学思维** | 数量、比较、计算、估算 | 数量 $\rightarrow$ 比较 $\rightarrow$ 计算 |
| **空间能力** | 方向、旋转、路径、空间关系 | 方向 $\rightarrow$ 旋转 $\rightarrow$ 路径规划 |
| **反应力** | 反应速度、规则切换、抑制控制 | 速度 $\rightarrow$ 规则切换 $\rightarrow$ 抑制控制 |

### 7.2 评分公式 (保持不变)
```text
performance =
  accuracy * 0.5
  + speedScore * 0.15
  + independenceScore * 0.15
  + difficultyScore * 0.20

newScore = oldScore * 0.7 + performance * 0.3
```

### 7.3 能力等级 (保持不变)
| 分数 | 等级 | 描述 |
|------|------|---|
| 0-39 | 正在成长 | |
| 40-59 | 基础阶段 | |
| 60-74 | 稳定阶段 | |
| 75-89 | 良好阶段 | |
| 90-100 | 优秀阶段 | |

### 7.4 错题分析与闭环系统

**分析维度**：
- 记录能力类型、题型、难度、错误次数、最近错误时间、是否重复错误。
- 例：因果推理 $\rightarrow$ 连续 3 次错误 $\rightarrow$ 触发推荐机制。

**巩固策略 (拒绝机械重复)**：
当孩子某种题型连续错误时，执行 $\text{错题} \rightarrow \text{巩固} \rightarrow \text{迁移} \rightarrow \text{提升}$ 路径：
1. **原题** $\rightarrow$ 2. **同知识点简单题** $\rightarrow$ 3. **相似题** $\rightarrow$ 4. **换场景题** $\rightarrow$ 5. **提高难度题**

### 7.5 趋势与推荐
- **趋势显示**: UP / DOWN / STABLE (保存 previousScore, currentScore)
- **智能推荐**: 根据能力画像弱项自动推荐训练项目 (例：阅读因果推理 < 60 $\rightarrow$ 推荐“森林里的秘密”专题训练)

## 8. 奖励与成长系统

### 8.1 激励机制
采用正向激励，禁止过度惩罚。通过多种资源驱动孩子的成就感。

**资源体系**:
- **星星**: 基础奖励，用于解锁关卡和能力等级。
- **金币**: 通用货币，用于购买简单装饰。
- **宝石**: 稀有资源，用于解锁高级角色或区域。
- **勋章/成就**: 记录里程碑（如：连续学习7天、专注力达到优秀）。
- **角色/家园装饰**: 将奖励转化为可见的视觉资产。

**获得规则**:
- 完成任务: +10 星
- 首次完成: +10 星
- 连续任务 (Combo): +5 星
- 高难度挑战成功: +5 星
- 完成冒险任务: 获得宝箱 (随机产出金币/宝石/勋章)

### 8.2 成就系统 (V1)
- **初试身手**: 第一次完成任意游戏

- **坚持不懈**: 连续学习 3/7 天
- **能力达人**: 专注/记忆/逻辑/阅读 任意一项达到 60分

## 9. 每日任务与习惯养成

### 9.1 脑力任务系统
每日随机分配一套任务组合，引导孩子均衡训练。

- 专注力 × 1

- **5-6岁**: 30分钟 / 日

## 11. 数据驱动设计与资源系统

### 11.1 资源管理 (ResourceManager)
建立统一的资源管理机制，确保所有资源在运行时可快速索引且支持本地化降级。

**资源清单 (`resource-manifest.json`)**:
记录所有资源的唯一 ID、类型、文件名、来源及用途。

**管理范围**:
- **图片**: 优先使用 Vector/Emoji $\rightarrow$ 本地 PNG/WebP。
- **音频**: 本地 SFX (短音效) + BGM (背景音乐) + 动物叫声 + 故事音频。
- **字体**: 统一使用 `res/font` 目录下的儿童友好字体。
- **故事资源**: 文本与同步高亮的时间轴数据。

### 11.2 数据驱动配置
禁止在代码中硬编码关卡和题目，所有内容通过 JSON 配置加载。

**资产目录 (`assets/data/`)**:
- `games.json`: 游戏元数据 (ID, 名称, 对应能力)。
- `levels.json`: 关卡配置 (难度、目标数量、时间限制、干扰项数量)。
- `questions.json`: 游戏题目 (内容, 选项, 正确答案, 解释)。
- `stories.json`: 阅读故事内容与分级。
- `reading_questions.json`: 阅读理解题库。
- `adventures.json`: 冒险任务序列配置。

**题目基础结构**:
每个题目至少包含：`id`, `type`, `difficulty`, `content`, `options`, `answer`, `explanation`, `ability`, `assets`, `audio`。

### 11.3 本地持久化架构 (Room + DataStore)

**Room 数据库实体**:
| 实体 | 核心字段 |
|------|---------|
| `ChildEntity` | id, nickname, age, avatar, interests |
| `AbilityEntity` | id, childId, abilityType, score, level, trend, updatedAt |
| `GameSessionEntity` | id, childId, gameId, difficulty, score, accuracy, duration, success, createdAt |
| `DailyTaskEntity` | id, childId, date, gameId, status, completedAt |
| `RewardEntity` | id, childId, type, name, earnedAt |
| `AchievementEntity` | id, childId, name, earnedAt |
| `LearningRecordEntity` | id, childId, date, totalTime, tasksCompleted, correctRate |
| `StoryEntity` | id, childId, storyId, title, dateRead |
| `AppSettingEntity` | id, key, value |

**DataStore (轻量配置)**:
`isFirstLaunch`, `selectedChildId`, `parentPin`, `dailyLimit`, `sessionLimit`, `soundEnabled`, `musicEnabled`。

## 12. 家长端优化 (Parental Control)

### 12.1 数据洞察首页
家长端的核心是将孩子的学习数据转化为可理解的洞察，而非简单的数字列表。

**重点展示指标**:
- **今日/本周概览**: 累计学习时间、完成任务数、综合正确率。
- **能力雷达图**: 8大能力维度的得分分布（视觉化呈现）。
- **阅读能力剖析**: 细分维度（信息提取、因果推理、人物理解等）的熟练度。
- **进步趋势**: 关键能力的得分曲线 (UP/DOWN/STABLE)。

### 12.2 智能分析与建议
- **错题分析报告**: 自动识别孩子在某种题型或能力上的重复错误。
- **个性化建议**: 基于规则的推荐。
  - *例：阅读因果推理 < 60 $\rightarrow$ "孩子在理解‘为什么’方面有困难，建议多尝试《森林里的秘密》专题训练"。*

### 12.3 设置与安全控制
- **学习限制**: 自定义每日学习总时长、单次会话时长。
- **儿童信息管理**: 修改昵称、年龄、头像。
- **安全锁**: 修改 4位数字 PIN 码。
- **隐私与关于**: 隐私政策、版本信息、关于 App。

**安全约束**:
- 儿童端严禁进入此区域 (必须通过长按图标 + PIN 验证)。
- 所有的配置修改立即生效于儿童端。

## 13. 非功能性需求

### 13.1 性能
- **启动时间**: ≤ 3秒
- **游戏响应**: ≤ 200ms
- **动画帧率**: ≥ 50fps
- **APK 大小**: < 50MB (无网络图片/音频外联)

### 13.2 安全
- 无网络权限
- PIN 加密存储
- 无个人信息收集
- 合规资源 (AI 生成 / CC0 / 商业授权)

### 13.3 测试
- **单元测试**: ≥ 80%
- **集成测试**: 游戏生命周期, 数据库操作
- **E2E测试**: 首页 → 学习 → 游戏 → 结果 → 首页
