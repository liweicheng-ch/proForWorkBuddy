### 架构技术栈
- **UI框架**: Jetpack Compose + Material 3
- **架构模式**: MVVM + Clean Architecture + Repository Pattern
- **导航**: Navigation Compose
- **状态管理**: StateFlow / MutableStateFlow
- **异步**: Kotlin Coroutines + Flow
- **数据库**: Room (SQLite)
- **轻量存储**: DataStore (Preferences)
- **图片加载**: Coil
- **音频播放**: Media3 / ExoPlayer
- **语音合成**: Android TTS (TextToSpeech)
- **依赖注入**: Hilt (可选，建议手动 DI 以减少依赖)
- **JSON 解析**: Kotlinx Serialization / Gson

## 核心约束提炼

### 硬性约束（违者终止）
1. **完全离线运行** - 核心功能零网络依赖，无后端、无云同步
2. **技术栈版本冻结** - JDK/Gradle/AGP/Kotlin 版本严禁升级
3. **真实实现** - 禁止假功能、禁止 Mock 数据充当真功能、禁止过度简化
4. **最小权限** - 仅申请必要权限 (WAKE_LOCK, FOREGROUND_SERVICE 等)
5. **80%+ 测试覆盖率** - 单元 + 集成 + E2E 全链路

### 关键设计决策
1. **数据本地化**: Room + DataStore + Assets JSON
2. **统一游戏生命周期**: IDLE → INTRO → DEMO → PLAYING → SUCCESS/FAILURE → REWARD → FINISH
4. **动态难度**: 1-10级自适应，错题回滚，连胜晋升
4. **音频统一管理**: AudioManager 单例，音效池 + BGM + TTS 三层
5. **阅读理解**: 100篇文章 × 6大主题 × 4级别(A-D) × 3题型

## 阅读理解内容规格 (PRD V2.2)

| 维度 | 规格 |
|------|------|
| **文章总数** | 100篇 (Assets JSON 存储) |
| **主题分类** | 6大主题: 动物、自然、科学、冒险、日常、情感 |
| **分级体系** | 4级: A(≤3岁) B(4岁) C(5岁) D(≥6岁) |
| **题型分布** | 细节找回 40% + 主旨推断 35% + 词汇语境 25% |
| **文章长度** | A级: 50-80字 / B级: 80-120字 / C级: 120-180字 / D级: 180-250字 |
